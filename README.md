## 📱 About

**Tickety** is a comprehensive and interactive Flutter application for discovering and booking events. Powered by the Ticketmaster API, it provides real-time event updates, interactive maps, and a seamless booking experience. It features an elegant UI with support for modern design practices.

## ✨ Features

- 📍 **Event Discovery** - Browse upcoming and nearby events across various categories.
- 🌍 **Interactive Maps** - View event locations on an interactive map using Google Maps.
- 🔐 **Secure Authentication** - User authentication powered by Firebase (Email/Password, Google, Facebook).
- 🎨 **Beautiful UI** - Fully built with Flutter, providing a smooth and responsive experience.
- 📴 **Offline Support & Caching** - Local caching for quick access to favorite events.
- 🎟️ **Event Details & Booking** - Detailed event information and streamlined booking process.

## 🛠️ Technologies Used

- **UI Framework**: [Flutter](https://flutter.dev/)
- **Architecture**: Clean Architecture + BLoC (Business Logic Component)
- **Dependency Injection**: [GetIt](https://pub.dev/packages/get_it)
- **Network**: [Dio](https://pub.dev/packages/dio) & [Ticketmaster API](https://developer.ticketmaster.com/)
- **Local Storage**: [Hive](https://pub.dev/packages/hive_flutter) & [Flutter Secure Storage](https://pub.dev/packages/flutter_secure_storage)
- **Authentication**: Firebase Auth, Google Sign-In, Facebook Login
- **Navigation**: [GoRouter](https://pub.dev/packages/go_router)
- **Location Services**: [Geolocator](https://pub.dev/packages/geolocator) & Google Maps
